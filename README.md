# Inventory Management System

A Python terminal based Inventory Management System with billing and JSON storage.

## Features

- Add Product
- View Products
- Update Stock
- Delete Product
- Search Product
- Low Stock Alert
- Billing System
- JSON File Storage

## Technologies Used

- Python
- JSON
- VS Code
- Git & GitHub

## How to Run

Clone the repository:

```bash
git clone https://github.com/adityag65/inventory-management-system.git
```

Run the program:

```bash
python inventory.py
```
